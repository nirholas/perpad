FAQ

Is this a hosted service?

No. It is a library and CLI you run yourself. You hold your own keys.

Does it make money?

No claim is made. Leveraged trading is zero-sum before fees and most traders lose. Paper-trade first.

Which models work?

Any Claude model with tool use. The default is claude-sonnet-5-5; set model in the config.

What does a tick cost?

A few LLM calls with short prompts. Cost scales with intervalSec and the model you choose.

Why only BTC and ETH?

It is a default allow-list, not a limit of the engine. Any Hyperliquid perp can be listed in markets; the exchange cap is read live.

How is liquidation handled?

Positions are isolated margin, so a liquidation loses that position's margin only. Paper mode models this with the exchange's maintenance margin formula; live mode is whatever Hyperliquid does.

Is it related to pump.fun?

The fee-split and profit-routing math is built for a pump.fun creator-fee flow, but the Solana legs are not shipped yet. See the roadmap.
