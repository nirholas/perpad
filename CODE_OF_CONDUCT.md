# Code of Conduct

Be respectful, assume good faith, keep criticism about the work. Harassment, discrimination, doxxing, and pump-and-dump solicitation are not welcome. Maintainers may remove content and ban participants who violate this. Report concerns via a private security advisory or by contacting @nirholas on GitHub.

This project adopts the spirit of the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
